
# Radix — site de apresentação

Página informativa do aplicativo Radix (estudo de loteamento e urbanismo), um aplicativo brasileiro 🇧🇷.

Idealizado e desenvolvido por Larissa Moura Nascimento — Arquiteta, Urbanista e Gestora Ambiental.

Este repositório é público e contém **apenas** o site estático de apresentação.
Não contém código do aplicativo, chaves, senhas ou dados de usuários.

Publicado com GitHub Pages: https://motherofmetal-droid.github.io/Radix-site/

## Arquivos

| Arquivo | Função |
|---------|--------|
| `index.html` | Página inicial |
| `404.html` | Página exibida quando o endereço não existe |
| `radix 192.png` | Logo do Radix, usado como ícone da aba |
| `radix 512.png` | Logo do Radix em alta resolução, usado nas páginas |
| `khepri-512.png` | Símbolo do aplicativo Khepri, usado no link |

## Aplicativos relacionados

- **Khepri** — aplicativo de projetos: https://appkhepri.streamlit.app/?lang=pt

## Observações

- Os endereços de imagem nas páginas são absolutos, porque a página 404 pode ser exibida em qualquer caminho do site.
- Ao trocar um arquivo de imagem, mantenha o mesmo nome ou atualize as páginas que o usam.
- O site é estático. Nenhuma informação de usuário é coletada aqui.
